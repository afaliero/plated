# Repository Instructions

- Whenever an architecture change is made, update the diagram in `README.md`.
- This repository is public on GitHub. Do not add sensitive information to tracked files.
- Explain planned actions before making changes. Clarify major actions or scope changes with the user before proceeding; do not infer approval for unrequested behavior changes.
- Follow the additional instructions in `apps/frontend/AGENTS.md` for frontend work and `apps/backend/AGENTS.md` for backend work.

## Git Workflow

When the user types `commit` or explicitly asks to commit changes, follow [the commit workflow](.agents/workflows/commit.md).
